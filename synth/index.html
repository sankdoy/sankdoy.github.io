CHEAT SHEET (what everything does)

Header

  • OFF/ON: starts/stops audio output (Web Audio needs a user click to start).
  • BPM: tempo used by time-synced LFO rates (1/4, 1/8, etc.).
  • GAIN: main output volume.
  • TRANSP: transpose all notes in semitones (+12 = 1 octave up, -12 = 1 octave down).
  • MIDI: load a `.mid/.midi` file, then Play/Pause/Reset using the current patch sound.
  • Preset: loads a saved preset from the dropdown.
  • RND: randomises lots of parameters to help find new sounds.
  • CODE: opens “patch code” — copy/paste to save/share/load a preset string.

Oscillators

  • Wave: waveform shape (Sin/Sqr/Tri/Saw).
  • Oct: pitch multiplier for that oscillator (1.00 = normal, 2.00 = +1 octave, 0.50 = -1 octave, 3.00 = octave+fifth).
  • Vol: how loud that oscillator is in the mix.
  • NOISE: adds white noise into the voice (useful for bite/air/percussion).
  • Noise Level: noise loudness (only active when NOISE is on).

Envelope (ADSR)

  • A (Attack): time to rise from silence to full volume after a note starts.
  • D (Decay): time to fall from full volume down to the sustain level.
  • S (Sustain): held volume level while the key is held (0–1).
  • R (Release): fade-out time after you release the key.
  • Graph: visual shape of the envelope you’re setting.

Parametric EQ

  • HP (High‑pass): removes low frequencies below the cutoff.
  • PK (Peak): boosts/cuts around a chosen frequency.
  • LP (Low‑pass): removes high frequencies above the cutoff.
  • Freq: the cutoff/center frequency.
  • Gain (PK only): boost/cut amount in dB.
  • Q: resonance/width (higher Q = narrower/more resonant).
  • HP/PK/LP buttons: toggle each EQ band on/off.

Modulation (LFOs)

  • Toggle: turns that LFO on/off.
  • Wave: LFO shape (Sin/Sqr/Tri/Saw/Custom).
  • Mode: Free (always running), Trigger (restarts on keypress), Envelope (one-shot per note).
  • Sync: when on, rate is set in musical divisions (BPM-locked). When off, rate is free Hz.
  • Depth: master modulation depth for this LFO.
  • Shape: opens a canvas editor. Right-click to add/remove points, drag to move.
  • Routes: connect the LFO to any parameter. Each route has a target and amount.
  • + LFO: add more LFOs (up to 4). + Route: add a new routing destination.

Effects

  • Toggle: enables/bypasses that effect block.
  • Distortion: adds harmonics/grit. Drive = amount, Tone = brightness, Mix = dry/wet.
  • Comb Filter: metallic/chorusy resonances. Delay (ms) sets the “tuning”, Feedback adds ringing, Mix blends.
  • Delay: echo. Time (s), Feedback repeats, Mix blends.
  • Reverb: space. Size (s), Damp (Hz) darkens/brightens, Mix blends.
  • Limiter: safety loudness control. Thresh = how hard it clamps, Knee = softness.

Output + Keyboard

  • Scope: waveform over time.
  • Spectrum: frequency energy (low → high).
  • Meter: output level.
  • Keys: A–L / W–P for notes. Z/X changes octave.
  • Tip: double‑click any slider to reset it to its default value.
